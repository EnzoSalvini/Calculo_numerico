# Cálculo Numérico

Repositório dedicado às implementações, experimentos computacionais e atividades da disciplina de **Cálculo Numérico**.

## Objetivo

Reunir algoritmos numéricos, análises de convergência e erro, visualizações e resoluções de problemas aplicados em ambientes como Python, conectando a teoria matemática à execução prática.

## Estrutura do Repositório

```text
Atv1CN: Realizada no dia 24/08/2026, dava início ao curso, envolvendo truncamento, arredondamento, erros absolutos, relativos e percentuais, além de Hagen–Poiseuille, criação de gráficos e GIF via código, sendo este último presente em Atv1_nanocateter.gif.
Atv2CN: Realizada no dia 02/09/2026, envolve tópicos como estabilidade, overflow e refinamento de malha em código.
Atv3CN: Realizada no dia 28/09/2026, trata dos métodos de encontro de raízes de funções via bissecção, Newton e secante, utilizando python para definição das funções e criação de GIF.
AtividadeAnimacaoGauss: Realizada no dia 30/09/2026, essa atividade envolvia criar uma forma visual de como a eliminação de Gauss age para resolver sistemas lineares.
AtividadeSistemasLineares: Realizada no dia 05/10/2026, focava em exibir as diferenças em resolver sistemas lineares manualmente e de forma automatizada.
AtividadeGaussSeidel: Realizada no dia 19/10/2026, retrata mais um método de resolução de sistemas lineares, este que é mais eficiente para resoluções computacionais.
AtividadePolinomioLagrange: Realizada no dia 11/11/2026, esta atividade demonstra as vertentes da interpolação via polinômio de Lagrange, suas especificidades e uma comparação com a extrapolação.
AtividadeErroInterpolacao: Realizada no dia 18/11/2026, utilizava de um problema físico para demonstrar como os parâmetros alteram a interpolação.
Além destas atividades, houveram outros manuais que foram entregue em papel, mas que não tenho acesso para subir uma cópia no github.

```

## Literatura Matemática:

TAHAN, Malba. O Homem que Calculava. 1938. — Obra literária que ilustra o raciocínio lógico, a proporção e a investigação de problemas práticos por meio da matemática, servindo como contraponto narrativo à resolução sistemática de problemas numéricos.
